# Codex Proposed C2 Conformance Cases

Status: proposed expectations for common-owner selection. No case below has
run or passed. These cases specialize the [common discriminators](../../../specification/conformance/README.md)
and the exact sources named below; they are specified before the documentary
implementation. Independent evaluators recover governing source and expectations
before opening the frozen subject. They do not assess their own authorship.

[Capabilities](../design/C2_CAPABILITIES.md) declare the claims; the
[build plan](../design/BUILD_PLAN.md) selects proposed thread groupings.
Selecting these expectations does not require all cases to run in every task.
Each actual trial binds its relevant claims, source, current subject and operating
envelope. Supplied judgments can test wiring; they cannot prove actual detection.

## First Actual-Use Thread Proposed For Selection

Start with Q05-Q08, Q13, Q14, Q19 and one Q21 defect. The subject is a small
source-backed method-document construction task in tenant-owned qualification
territory. A fresh worker uses the published slice to recover the governing
contract and produce an actual document change. An independent assessor consumes
the frozen output and the independently specified obligations. This tests use
of the method, rather than merely asking actors to restate it.

The supplied task includes one coupled interpretation/authority relation and
an independently specified completion condition. Positive material is checked
before a single isolated actual omission is introduced. The assessor must detect
that omission. The document is repaired under a new bounded Writer activation,
then re-assessed against unchanged expectations. Clearing incidental actor
context tests re-entry over retained workspace progress; a separate small
possible-external-effect case tests Q16 when that effect profile is selected.

The task's exact envelope, available sources, permitted effects, actual defect,
independence and completion interval are bound at activation. C2 fixes the
obligations and expected distinctions, not a universal cap or fixture program.
A required coupled relation that cannot fit returns a limit; it is not diluted
until the actor obtains a pass.

## Judgment And Next Action Are Different Types

Use RF-012's recovered judgment distinctions: satisfied, falsified,
indeterminate, out_of_frame and invalid_basis. AC-007 also preserves failed,
missing, indeterminate, out-of-scope and invalid-basis pressure in its declared
constraint algebra. A projection between these accounts retains the original
cause and claim; it is not evidence that their whole domains are identical.

| Observation pressure | Proposed permitted-disposition expectation |
|---|---|
| Supported satisfied claim with authorized work remaining | Continue only inside the still-live grant. |
| Falsified candidate; cause and bounded repair supported | Repair at the owning layer, then reassess affected claims. |
| Missing/indeterminate evidence | Obtain admissible evidence or return a truthful unresolved result. |
| Insufficient context/capability | Use supported refinement/reconfiguration, or yield/terminate with unresolved obligations. |
| Invalid subject/basis or incompatible join | Reacquire/rebind the affected relation; no dependent success. |
| Possible unobserved effect | Reconcile sufficient state, or preserve uncertainty and withhold unsafe repetition. |
| Exhausted, withdrawn or out-of-scope authority | Conclude/return to its owner; evidence cannot renew the grant. |

This is a proposed finite boundary account with an unknown-pressure route. It
does not claim all world states are known or every provider call terminates.
Its observation/supervision assumptions require their own selected evidence.

## Detailed Negative-Result Conservation

For Q11, first establish an adequate candidate and actual material for A's
responsibility. Introduce one real defect, obtain an authenticated independent
negative judgment with source citations, and preserve its original producer.
Authenticate every planned assessment. Leave a distinct required obligation B
outside the supplied applicable coverage. Aggregation retains A's failure and
B's uncovered status; neither can replace the other. Later changed candidate or
basis can reopen applicability while the original judgment remains historical.

Q12 deliberately omits a planned judgment and expects the earlier authentication
guard to reject it. Repairing Q11 must preserve this guard. Supplied false
judgments are insufficient for the actual-defect detection claim in Q21.

## Operational Evidence

Each selected performance claim records its operating envelope and all material
work, attributing method/framework preparation, external actors, assessment and
human interventions separately when observable. Useful measures include selected
context bytes/tokens, admitted or transferred bytes, repeated acquisition,
preparation memory, critical-path elapsed time and aggregate work. Unavailable
provider counters remain unavailable; bytes are not secretly token counts.

For Q22, compare semantically adequate results on the same relevant task and
basis. Count displaced work. Select bounds for that workload and hardware where
the claim needs them; a universal payload, RSS, retry or time quota is not
introduced. If no adequate baseline exists, report observations and withhold the
improvement claim.
