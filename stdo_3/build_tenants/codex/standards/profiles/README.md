# Optional Profiles

Standing: Codex candidate profiles for review. These documents add selected
domain meaning to [Spec Method](../SPEC_METHOD.md). Installed STDO 2.5.1 RC2
governs their construction; optional placement does not remove any duty from
that operative builder basis.

## PR-01 Select A Profile

Select a profile through the governing Product/design relation when its domain
obligations apply. Bind its exact source/basis, subject, affected relations,
responsible owners and scope. Selection preserves common WHAT and required core
obligations. Co-location or a matching domain label supplies no implicit import.
Unknown applicability remains unresolved before dependent promotion.

| Profile | Owns within selected scope | Exact recovery owner |
|---|---|---|
| [Software](SOFTWARE.md) | Software semantic design, admission, composition and effect boundaries. | RC2 DESIGN_MODULE_METHOD.md and the Product's accepted design. |
| [Graph execution](GRAPH_EXECUTION.md) | Typed graph assets, vectors, graph functions and traversal bindings. | RC2 ODD_METHOD.md; selected graph/runtime contracts own their mechanics. |
| [Work records](WORK_RECORDS.md) | Work identity, carrier lifetime, state and truthful projections. | RC2 TICKET_METHOD.md; the selected Product owns concrete carriers. |
| [World model](WORLD_MODEL.md) | Recovered entities, treatments, semantic publication and scoped overlays. | RC2 WORLD_MODEL_METHOD.md and authoritative source domains. |

## PR-02 Import Core Responsibilities

[Foundations](../FOUNDATIONS.md) owns contextual meaning, identity and typed
conservation. [Work](../WORK_METHOD.md) owns activation, execution and current
state recovery. [Evidence](../EVIDENCE_METHOD.md) owns judgment, independence and
conjunction. Profiles supply their domain bindings rather than rival definitions
of those relations. Combining profiles requires compatible obligations and
explicit owner/source routes under [S-04](../SPEC_METHOD.md#s-04-derive-interfaces-from-outer-outcomes).
