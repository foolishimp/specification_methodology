# Codex Documentary Method Entry

This is a candidate realization of Jim's selected STDO 3 scope. Installed STDO
2.5.1 RC2 governs its construction. The common WHAT remains in
[specification](../../../specification/PRODUCT.md); these document names and
routes are Codex HOW. [Current evidence and standing](../qualification/BUILD_RETURN.md)
are separate from the method. Presence does not make an installed release.

## Begin With Your Current Work

Recover the selected outcome, exact bounded job, subject/basis, permitted
effects, exit and stops under [W-01](WORK_METHOD.md#w-01-bind-the-selected-work).
The surrounding Product demand constrains that job; it cannot replace it.
Recover sufficient material under [W-02/W-03](WORK_METHOD.md#w-02-acquire-sufficient-context),
then perform and observe the authorized work under [W-04](WORK_METHOD.md#w-04-transform-and-observe).
Missing source, unfit context or uncertain effects have truthful dispositions.

Use [Evidence](EVIDENCE_METHOD.md#e-01-bind-a-claim-and-its-support) for the
required claim/assessment and compatible conjunction. Keep failures, uncovered
coverage, original producers and decision authority distinct. Choose only the
next authorized action under [W-05](WORK_METHOD.md#w-05-select-the-next-authorized-action).
For a restart, read current persistent work and affected dependencies under
[W-06](WORK_METHOD.md#w-06-re-enter-current-persistent-work); useful progress
survives and an unfinished assessment stays unfinished.

These routes do not grant effects or prescribe a universal sequence. One
sufficient capable context can act directly where allowed. Import only material
owners; the [source and task index](SOURCE_INDEX.md) recovers deciding sources
when a view is insufficient or disputed.

different responsibility instances. Interface count does not count semantic
primitives. Sharing preserves required independent assessments and distinct
decision owners. Domain strategies and test fixtures remain outside core law.
