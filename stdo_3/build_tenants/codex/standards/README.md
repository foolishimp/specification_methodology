# Codex Documentary Implementation

This territory will hold the tenant's method-document implementation against selected common WHAT.

Document names, grouping and reader routes are tenant HOW unless an accepted common publication boundary constrains them. The expressed method semantics must satisfy the common contract; they do not replace construction specifications.

C1 is accepted for this tenant. The [C2 build plan](../design/BUILD_PLAN.md#proposed-canonical-document-owners) assigns canonical meanings to Foundations, Spec, Work, Evidence, Qualification and optional domain profiles. Its first thread constructs only the clauses and reader routes needed for one actual-use path, then expands through affected joins.

Common C2 capability and acceptance selection remains open under [Product Checkpoints](../../../specification/PRODUCT.md#checkpoints). This directory contains no completed STDO 3 standards or observed actual-use results yet.
