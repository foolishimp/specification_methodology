# Findings logged at the 0.1.0 cut, not fixed

Commentary, not law. Author: Claude, as Executive. Date: 23 November 2026.
Release 0.1.0 is cut from `1e3abb307`. The bar was the product owner's: a
sunny-day steel thread and the guard rails holding; lesser findings logged.
None of these stopped the thread.

1. **Work beyond the change, inside one asset.** In the steel thread a ticket
   that added one option rewrote 27 lines of the intent and 51 of the product
   definition, and closed. Where the user decides, only the user stops it.
2. **A question or an evaluation spent before work that is plainly needed.**
   Where an asset is there and a ticket changes it, the framework asks or
   judges first. Measured: 1.78 to 5 USD each time on Builder itself.
3. **The attempt limit counts a working session that ends without an
   evaluation.** One of three attempts on the log-and-ticket work bought no
   judgement.
4. **Stale text is found one batch at a time.** Two evaluations said no for
   comments and design entries that still described removed files. A session
   that removes something is not told to search for every mention of it.
5. **Acceptance from earlier tickets is read from done tickets.** That
   reading grows with the number of done tickets (REQ-ALG-004).
6. **A ticket's branch and checkout remain after its merge.** In a larger
   repository each ticket leaves a branch `stdo/<ticket>`.
7. **A workspace built before 0.1.0-rc.5 counts every earlier acceptance as
   absent once.** On Builder itself that cost one round of judging.
8. **A session that writes a protected file is stopped and named; the file is
   left as the session wrote it** for the user to put right, since the
   framework never rolls the workspace back.
9. **The cost of a session grows with the product.** About 1 USD on a Hello,
   2 to 10 USD on Builder itself.
10. **For the product owner:** the phrase "whether it is small work" in the
    product definition; Builder's own licence (REQ-INTERFACE-005, Deferred);
    the two interfaces not built (REQ-INTERFACE-001) and the two verification
    requirements (REQ-VERIFY-002, 003), none marked Deferred; the release's
    name and version.
