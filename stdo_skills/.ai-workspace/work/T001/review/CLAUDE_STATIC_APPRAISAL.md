Current frozen file hashes still match; this is not a claim they were modified. Correct the validator or narrow its claims while separately supplying the required resource proof.

**F-C04 — S2: update/removal do not establish the selected owned installation.** `INSTALL.md:50–65` and `stdo-release-install/SKILL.md:45–65` hash one SKILL.md, then delete named directories; removal performs no identity check.
