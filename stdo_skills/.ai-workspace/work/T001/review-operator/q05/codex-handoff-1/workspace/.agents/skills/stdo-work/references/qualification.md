# Qualification boundary

Common requirements and scenarios remain exact external authority in [source routes](../source-routes.json). Derive expected outcomes independently before acquiring the tenant answer. Freeze an isolated workspace, exact source/package/tool/method cuts, authority, host/model/settings, input exposure, time/resource bound and lane. Automatic discovery and explicit invocation are separate attempts; a fallback never erases an automatic failure.

| Required case | Evidence needed; current construction standing |
|---|---|
| Q01 | Ordinary request discovers skill and performs bounded tool-backed change; fresh explicit lane; actual host unperformed |
| Q02 | Unrelated task avoids forced STDO setup; actual host unperformed |
| Q03 | Valid pin and missing/altered/ambiguous variants; actual host variants unperformed |
| Q04 | Sufficient one-file direct Writer uses focused proof without invented ticket/coordination/review; author walkthrough only |
| Q05 | Actual worker handoff and source-first independent reviewer; unperformed |
| Q06 | Actual unsupported/error response retained and dependent success withheld; host trials unperformed |
| Q07 | Equal bytes with accepted history versus unresolved counterexample cause distinct continuation; author walkthrough only |
| Q08 | Changed target with lost acknowledgment reconciled before retry; host trial unperformed |
| Q09 | Material source/candidate change withdraws affected review reliance only; unperformed |
| Q10 | Incomplete availability, inconclusive assessment and unperformed assessment remain distinct; unperformed |
| Q11 | Preparation-only authority and separately authorized local deployment; unperformed |
| Q12 | Scoped install/invoke/update/remove with resource and unrelated-config checks; unperformed |

Retain each actual invocation, input delivery, source acquisition, output, tool trace, effect/postimage, per-predicate verdict and counterexample, residual and invalidator. Measure elapsed time and reported tokens/cost; unavailable data stays unknown. Include retries, repair and review in total cost and compare equivalent substantive information. One successful trial is bounded evidence, not a reliability estimate or general efficiency benefit.

Run the cheapest focused check capable of falsifying the current change; expensive whole-candidate host qualification belongs at its declared boundary. The read-only package verifier checks actual metadata, resource containment and file inventory. It does not grade semantic success by keywords. Author instruction assessment must separately inspect the actual bodies and reason through Q04, Q07 and Q06/Q08. Independent review and all mandatory host cases remain necessary for initial delivery; construction cannot silently waive them.

Host/tool/method or prompt changes identify affected trials and claims. Retain unaffected evidence with a justified currentness relation. Tune from observed failures rather than accumulating universal process.
