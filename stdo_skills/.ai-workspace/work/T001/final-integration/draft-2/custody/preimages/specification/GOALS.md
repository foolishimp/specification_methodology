# Goals

## Current selection

[T-001](../.ai-workspace/tickets/active/T-001-skills-dogfood.md) constructs the new
STDO Skills Product using static released STDO 3.0.1 RC1 and current tooling.
The common WHAT is shared; Codex and Claude receive independently designed and
tuned build tenants. This is the initial practical test of the method on its own
agent tooling.

Current common documents are candidates awaiting Root's exact construction
disposition. Bootstrap installed-basis verification is evidence about the basis,
not proof of the skills. Tool compatibility assessment is in progress.

## Delivery outcomes

1. Verify the immutable method pin and preserve it throughout construction.
2. Establish common capabilities, discriminators, frame basis and work authority.
3. Resolve the tool contracts required by the selected lifecycle paths.
4. Construct independent Codex and Claude designs and working skill packages.
5. Exercise matched finite scenarios on actual hosts and inspect actual tool calls.
6. Obtain independent assessment, repair supported defects and present a bounded
   delivery result with all remaining limitations.

The [T-001 ledger](../.ai-workspace/tickets/active/T-001-skills-dogfood.md#execution-plan-and-ledger)
owns detailed progress. Publication, fleet deployment, global default changes and
general efficiency claims are outside the initial delivery result.
