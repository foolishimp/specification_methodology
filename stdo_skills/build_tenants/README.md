# Host bindings

Codex and Claude share the current [Skills design](../specification/DESIGN.md),
[adapter](../skills/stdo-context/SKILL.md) and installer. Each `current/` tree owns
only host presentation and optional visual instructions. Core workflow meaning
comes from the exact installed native method; Purpose Context is independently
owned. Earlier tenant designs/skills/tests are archived in the exact alignment
preimages and prior evidence, not alternate current implementations.

Use [Getting Started](../GETTING_STARTED.md) for purpose selection, ordinary QA
and boundary use; [installation](../scripts/INSTALLATION.md) covers both hosts.
