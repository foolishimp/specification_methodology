## Release Delta

### Coordinated Release-Matched Asset Cohort

Release Method now defines one explicit cross-Product cohort for STDO and its
required indexes. One complete stack cut carries the exact STDO corpus,
distributed plugin, Axiom Indexer mechanics Product, STDO Representation
Product, and released `a_c.STDO` program and logical constraint map under the
same exact cohort version suffix. Product cut names add `v`; embedded plugin
and index fields use the same suffix without `v`. Product identities and authorities remain
distinct.

A missing, stale, differently versioned, or source-digest-incongruent member
blocks the cohort. The semantic index binds the complete exact standards member
inventory, member digests, member-set digest, and cut identity. A source-member
change therefore requires regeneration and qualification under the same new
cohort cut; an older index remains only immutable history.

Construction uses two commits to avoid a tag-object hash cycle. Commit A
freezes STDO and plugin, then a local unpushed annotated STDO tag produces the
exact installed-manifest identity. Commit B freezes the derived Products,
semantic index, and cohort record against that identity. One atomic transport
publishes main and the complete three-Product RC, immutable-tag, selector, and
release-branch ref set only after a post-tag, pre-push local-ref-graph gate
verifies every annotated object, peel, target, version mapping, and exact push
ref. The gate binds expected remote OID or required absence for every
destination. Immutable tags are create-only; every mutable ref uses an explicit
per-ref compare-and-swap lease in the same atomic push. Remote drift requires a
refetch and complete requalification. Unsupported atomic transport or any
partial remote cohort refuses.
