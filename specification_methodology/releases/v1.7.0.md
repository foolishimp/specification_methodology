## Material Changes

### ODD_METHOD §11.7A Conforming Agentic Development

`ODD_METHOD.md` now ratifies conforming agentic development as ODD worksite law,
scoped to the graph-native worksite and composing `SPEC_METHOD.md` and
`TICKET_METHOD.md` rather than re-declaring them.

Conformance has two halves:

- **The walkthrough is the conformance proof (F_P).** An agentic coder executes
  the constitutional process end-to-end on real work from a minimal declared
  authority packet. A point the walkthrough cannot pass is a method defect only
  when a competent agent, correctly configured and using the declared authority,
  still cannot decide; that defect is repriced into the owning authority
  surface. An agent that ignored authority, used stale memory, or reasoned badly
  has produced agent error, not a method defect. The proof is independent of any
  automated runtime: a live lane hostage to external execution conditions cannot
  prove process validity, because it conflates process validity with runtime
  availability.
- **The validator is the conformance gate (F_D).** Constitutional artifacts are
  admitted under `SPEC_METHOD.md` and `TICKET_METHOD.md` deterministic criteria.
  ODD requires only that agentic development pass through that admission — a
  check on output, not context the agent must hold. Conformance is not
  approval-by-usage (§9).

The section is threaded into the check surfaces:

- §16 Failure Pattern item 15
- §19 Ramp-Up Checklist question 14
- §20 Canonical Compression

### Authority Compression Distribution

`specification/standards/authority_compressions/` publishes source-maintained
compressed read models for installed workspaces that need compact shared-method
authority. Each compression carries its source path and digest and is marked
`stale_if_source_digest_changes: true`. Per the bundle README, a changed source
digest makes the compression stale and requires regeneration or explicit
reacceptance before install use.

This release pins both bundles to the §11.7A-bearing `ODD_METHOD.md`:

- `ODD_METHOD.md` digest:
  `e420024069307ec0de189b3e6e401058db063dfdcc8c701fee3088e844f060f4`
- `odd_method.compressed.md` and `stdo_compressed.md` carry the conforming
  agentic development rule and cite that digest

`specification/standards/README.md` documents the `authority_compressions/`
distribution surface.
