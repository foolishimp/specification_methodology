# Complete STDO release cohort

The owner's selected public version line 3.0.5 delivers five peer Products at
the exact RC cut 3.0.5-rc.1: Specification Methodology v3, STDO Representation,
a_c Implementations, Axiom Indexer and STDO Skills. Their ownership and
acceptance remain separate. The root `stack_release.json` selects their
complete candidate subjects and dependency edges; `STACK_RELEASE.md` owns
the repository's coordinated construction and promotion procedure.

Required components are the native plugin, manager, current source-matched
model/map/index, unified 3D/2D/layered explorer with source/files navigation,
Graphify and executable Lean tools, exact-candidate Lean evidence, proof
reader, and Codex/Claude skill distributions. Historical snapshots remain
history. They cannot satisfy current representation, proof or installable-use
claims. A source archive or CLI help alone does not qualify executable use.
Third-party packages retain their own exact versions and provenance.

One explicit semantic-source freeze precedes derived assets. Its full source
inventory classifies normative owners, native skill contracts and derived
frames, and identifies generated documentation/tooling exclusions. The
representation and its views bind that source identity. Final release binding
then relates those exact bytes to the complete native cut and installed
manifest without requiring a manifest to contain its own digest.

The release closes only after exact membership/currentness, shared cohort
version, dependency and provenance checks, required independent assessment,
installed qualification, atomic complete-ref publication, public readback and
fresh acquisition pass. Missing or failed required evidence withholds the
dependent claim. No new consumer adoption is implied. The source project
continues to use its selected released 3.0.4 builder during this construction.

The owner explicitly authorized resetting the unadopted former stable 3.0.5
line to immutable RC cuts plus moving version selectors. The exact grant,
old tag objects and assets are retained in `STDO305_RC_RESET`. This exception
changes no other release or Product adoption. All five owned versions carry
the RC suffix; Python wheel metadata uses the checked PEP 440 spelling
`3.0.5rc1`. Public title `STDO 3.0.5` and normal/Latest status describe the
qualified fixed RC release, not a mutable exact-install identity.
