## Qualification obligations

Assess the changed guidance independently from its author against exact
governing sources and a frozen changed subject. Derive realistic expectations
before candidate acquisition. Retain actual outputs for ordinary test-closed
repair, each causal route, capability/complexity failure, changed-scope re-entry,
named boundary review, unrelated findings, incomplete evidence/coverage,
required recheck and valid-support reuse. Cover the native work and review
entry paths and distinguish source assessment, actual use and host behavior.

Word-presence or schema checks prove no behavioral decision. A bounded trial
supports only its declared subject, actor, scope and conditions. Preserve
unperformed cases and inherited evidence limits. Installation and automatic
host triggering need their own observations; broad effectiveness, release
qualification and publication are separate boundaries. The default and local
adoption must agree before this source increment is returned complete.

For the ticket/context continuation, fix source-first expectations before
candidate exposure and retain a fresh actor's exact ticket, inputs and outputs
without the previous private conversation. Cover a contrary summary, valid
support, invalidated evidence, uncertain external completion, missing
admission/write authority, a sufficient non-ticket carrier and a material
context boundary. Independently assess the owner placement and each affected
projection. Mechanical frame identity and these finite observations do not
establish general context sufficiency or automatic host behavior.
