# STDO 3

STDO 3 is a new source project constructing a specification methodology as documents. One common WHAT governs independent Codex and Claude build tenants.

The installed STDO 2.5.1 RC2 cut governs construction. The STDO 3 foundations are working content for review, not adopted builder law. The existing STDO 2.* source project and release-matched cohort remain separate.

## Start

1. Resolve [stdo_3.json](stdo_3.json), verify its exact installed basis and load its declared bootstrap entrypoint.
2. Read [Intent](specification/INTENT.md), [Product](specification/PRODUCT.md) and [Goals](specification/GOALS.md) under that basis.
3. Read the [working principles](specification/requirements/PRINCIPLES.md) and [common checkpoint ticket](.ai-workspace/tickets/active/T-001-common-definition-and-checkpoints.md).
4. Select [Codex](build_tenants/codex/README.md) or [Claude](build_tenants/claude/README.md) for the initial independent principles attempt.
