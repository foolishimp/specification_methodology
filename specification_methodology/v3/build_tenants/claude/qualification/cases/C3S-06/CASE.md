# C3S-06 Configuration: allocate a multi-part task across finite actors

Identity: `urn:stdo-3:claude:case:C3S-06`. Part of the C3 cross-synthesis
rebuild's usability evidence. Status: designed. No run is recorded for this case.

## Claim under test

A fresh actor given only one projected frame of the C3 cross-synthesis
candidate and the task chooses and justifies a configuration from the task's
own operations, dependencies, actor capabilities, context capacities and
assurance requirement. It must not prescribe a role inventory or hierarchy,
and it must keep these distinctions:

- context fit is measured in bytes, and capacity pressure never licenses
  omitting material;
- an author's fresh context does not make an independent assessor;
- a compact result that omits a blocker present in the workspace is not
  enough for the next decision;
- adequacy and optimality are separate claims, and familiarity supports
  neither.

It then evaluates one stated check and reports the core value, the deciding
facts and the evaluation that was not performed.

## Task

[TASK.md](TASK.md), product `tide-tables`, is a new task written for this
case. Its subject is invented and is evidence about no real product. The
