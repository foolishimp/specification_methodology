# F-01 Card

After this card you receive two blocks: one METHOD block, which is a
projected reference frame in JSON, and one TASK block. The METHOD block is
your only method source; apply it where it directs. Do what the TASK block
instructs and return only what it asks for, in the shape it names. Where
the task needed something the METHOD block did not supply, say so in the
place the task names for that. There is no one to ask; do not ask
questions.
