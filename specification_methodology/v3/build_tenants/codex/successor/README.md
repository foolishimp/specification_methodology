# STDO Specification Methodology

Author: Dimitar Popov.

STDO governs purposeful construction through specification, typed composition,
bounded evaluation and authorized disposition.

`3.0.0-rc.4` is this package's unaccepted, unpublished candidate target; its
manifest version does not identify an issued release cut.

The [standards library](standards/README.md) is the method entry. Its
[task routes](standards/README.md#choose-a-task) locate the deciding owners for
intake, recovery, evidence reuse, assessment and disposition.
[Foundations](standards/FOUNDATIONS.md) states the premises. The
[transformation library](standards/TRANSFORMATION_LIBRARY.md) defines shared
conditional contracts. Particular methods own their concrete types, policy,
refinements of the single result algebra and authority.

[Responsibility views](standards/README.md#foundations-and-shared-library) project
selected clauses for bounded tasks. Plugin skills route actors to sufficient
material and the exact basis selected by their Product Definition. Views and
skills preserve their owning clauses and confer no operation or decision grant.

The [method interpretation](interpretation/README.md) represents the source
determinations and their dependencies for bounded acquisition. Its source
inventory identifies the document subject; its encoding theory, carrier and
checker have separate coordinates. Structural validation does not establish
semantic fidelity or acceptance. Assessing an explicitly selected source
package does not adopt it as the actor's governing method or install a release.
