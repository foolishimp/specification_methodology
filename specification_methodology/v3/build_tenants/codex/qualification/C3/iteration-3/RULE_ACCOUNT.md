A stable determination ID is `MEMBER.anchor`; paths are relative to
`successor/`, and anchors omit `#`. A row is an accounting unit, not a claim
that one heading is one independent law. `source_members` pins each member
once. `owner` carries the exact immediate-heading body hash and diagnostic
lines. Each local `cN` clause resolves as `row-ID#cN`; its byte span and digest
permit exact reacquisition. Heading children have separate rows. The account
contains 3,436 exact block routes without copying the complete source bodies.

`representation_kind` distinguishes `constraint`, `definition_data`,
`consumer_binding` and `non_deciding_locator`. `interpretation_standing`
distinguishes bounded author bindings from available source that still needs
construction. Null `predicate` on a definition or locator asserts no Boolean
assessment; on a pending constraint it records unfinished decomposition.
Neither is a domain `indeterminate` verdict. Actual task observations, grants
and assessment results are separate inputs.

`dependencies` and `consumers` contain stable IDs. `dependency_relations`
separates contract application, governing scope and source reference; a link
is not a logical premise. `applicability_ref` resolves the shared owner-family
scope, while a row's explicit applicability retains its narrower condition.
`argument` distinguishes source premises, conditional consequence and owned
policy. An argument route is not an independently proved entailment. Source
clause roles are acquisition hints; lexical matches cannot decide modal force
or prove that no exception exists.

Common limits, owner scopes and unfinished-work descriptions occur once.
Source metadata and work partitions refer to IDs rather than repeated owner
records. The semantic package projection must omit comparison, construction,
review and reduction accounting. It may encode definitions directly, but must
not convert uncompleted constraints into invented predicates or complete
coverage. The compiler should consume the later consolidated semantic account.
