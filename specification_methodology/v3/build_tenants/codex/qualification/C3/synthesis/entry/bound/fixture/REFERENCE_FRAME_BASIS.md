# Fixture Reference-Frame Basis

This fixture uses the exact installed [STDO Reference-Frame Baseline](stdo://releases/v2.5.1-rc.2/standards/STDO_REFERENCE_FRAME_BASELINE.md),
within the subject and authority of [its execution contract](EXECUTION_CONTRACT.md).
No baseline role, required evaluation or independence obligation is removed.
The acting model inspects the task and current files, selects the applicable
ordinary work route and returns proposed edits. The host is the separately
bound executor and fixture evaluator; it observes actual files and records
application or rejection. The actor may not assert those later effects.
Task-specific acquisition follows the selected method's ordinary entry; this
basis does not supply a selected task frame or task solution.
