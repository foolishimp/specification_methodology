# Task and frame coverage

X5 is adapted as a task-to-route account. A task may use a reusable assembly;
one file per task and a universal numeric cap are not imported. The installed
builder and each actual activation still bind its subject, task material,
authority, capability and envelope. A rule excerpt alone is not that frame.

| Required task or material condition | Current route or intended assembly | Qualification owed |
|---|---|---|
| Bootstrap, select authority and discover the active work | Package README, getting-started route and ordinary work skill | Ordinary discovery, current basis and admitted task; no supplied expected answer. |
| Construct or assess one member against common requirements | `MEMBER_CONSTRUCTION_ASSESSMENT` assembly | Actual member work with requirement inputs, candidate subject, permitted effects and independent assessment. |
| Triage a new defect or requirement change | `TRIAGE_CARRIER` | Correct re-entry and owner; classification cannot grant a repair. |
| Resume from current workspace after stale context or interruption | `WORK_RECOVERY` with actual work/effect observations | Retain valid work; preserve uncertain material effects before dependent action. |
| Evaluate and combine results across domains | `EVALUATION_CONJUNCTION` | Failure plus missing coverage, reason-sensitive mappings, performance and effects. |
| Bind a human or mixed process to the requirements | `DOMAIN_BINDING`, extended with the generic tenant binding | Concrete calculus, execution binding, resource boundary and applicable evidence. |
| Judge a typed join or faithful source transformation | `CONSTITUTIONAL_DERIVATION` or `DOMAIN_BINDING`, selected for the actual adopted profile | Preserved triggers, modal force, exceptions and outer predicate. |
| Determine member acceptance and release readiness | `RELEASE_ADOPTION` with the actual Product's acceptance criteria and decision grant | All applicable criteria, unresolved replacement and exact release identity; no authority inferred from a test. |
| Acquire a native interpretation slice | Explicit native index, current bindings and source routes | Ordinary selection and fidelity on the selected domain, including conditional/profile applicability. |

The member construction assembly and the affected existing routes address
task gaps in the previous six-frame package. Their actual bytes and source
routes are frozen in the current frame input account. Until that generation is
complete, this is a construction plan. Product-specific criteria belong in the
activated task, not in a universal method frame. A generated route and passing
excerpt check establish neither task sufficiency nor criterion 4.

Old I3 trials retain their exact packets and tasks. No result is relabelled I4.
The shared protocol is supplied by the authorised nonauthor after both
candidates freeze, or committed by digest before disclosure. This builder does
not author that comparison's expected answers. Unknown retained host context
and unselected resource allowances remain explicit.
