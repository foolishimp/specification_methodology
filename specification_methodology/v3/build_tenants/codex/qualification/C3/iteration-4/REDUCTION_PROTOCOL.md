## Dimensions and result limits

For each task record the actual owning determinations, distinct domain
refinements, rival determinations of the same question, and reconciliations
needed to reach a decision. A pointer is not another decider. A family-table
row is not a reduction witness unless the actual consumer uses its owner.

Measure entry bytes, cumulative acquired UTF-8 bytes including rereads, and
route hops independently. Record a retained-context bound only when the actor
or runtime can establish it; emitted bytes and a proposed release schedule do
not measure actual retained attention. Native host context and charges remain
unknown unless observed. Wall time names its measurement boundary.

A narrower elimination witness requires one removed rival determination or
reconciliation, preservation of every guard on the same cases, and the
surviving owner and consumer. A broader improvement claim also accounts for
adverse changes on both baselines. If the current source merely explains an
existing shared determination better, report explanatory improvement and no
new deciding-path reduction. No universal percentage or shorter-text target
is introduced.

Expected tradeoffs are declared now: fuller argument tables and their frame
excerpts increase acquisition bytes; separate consumer/owner routes can add a
hop; explicit result refinements preserve necessary domain choices. None is
automatically beneficial. A source-reading assessment and a practical
actual-use trial remain different evidence. The eventual common comparison
uses its own shared conditions and owner decision.
