`stdo://releases/v3.1.0-rc.3/`. Its exact native predecessor is RC2,

## Corrected method

Every normative tier, including optional profiles, defines its terms and rules
within STDO. Downstream product names and installation folders no longer supply
method meaning. ODD retains graph terms, ownership, authority and evidence rules.
Tracking obligations, decisions, progress and unresolved matters, conserving
needed step-produced facts, and reconciling with the authoritative mutable
workspace remain required. A generic register is an optional example tool.
Equivalent LLM or other mechanisms may provide this functionality. No immutable
ledger, event-log architecture, fixed evaluator API or universal replay design
is imposed by ODD. Declared Product-specific evidence obligations still apply.

Product defines the intended product and end state, including capabilities still
to be built. Goals hold the current epics or work wave. The owning specification
method, templates, guides and generated frames now express the same distinction.
