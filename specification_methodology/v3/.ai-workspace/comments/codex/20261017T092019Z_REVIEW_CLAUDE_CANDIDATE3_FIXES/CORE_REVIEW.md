## Remaining Finding R5-C1 — A New No-Action Judgment Loses Its Result After Closure

**Severity: medium.** The affected method can lose a material refusal or
authority determination when combining or consuming current results. The source
still forbids unlawful action, so this finding does not establish that an
implementation actually performed an unauthorized effect.

At A `standards/ODD.md:1019-1038`, the repaired owner explicitly recognizes typed
no-action as a material determination. Its predicate at 1029-1030 is “a published
lawful action can be selected for the current gap on the exact basis.” Yet
1024-1027 exempts no-action after `post_retry`, `post_repair`, `post_reenter`,
`post_block` and `post_reprice`: the preceding closure carries the core value and
“the no-action adds none.”

That preceding value answers a different question. A8 at
`standards/ODD.md:1118-1124` binds it to “the edge's obligations are fulfilled on
the exact basis” and expressly separates predicates. The function table at 865
repeats the omission by adding a selection core result only when no closure
decision precedes the no-action. The foundation-to-law row at 130 makes the same
restriction. The source-disposition summary at 1859 is additionally stale: it
still says selection, including typed no-action, maps to no core at all, even
though the initial branch now does.

A discriminating case is:

1. An attempted edge returns `retry(defeated)`. Its admitted counterexample
   defeats edge fulfillment for that attempt, so A8 returns `falsified` at
   1137-1140 and 1161.
2. The subsequent selection acquires the required fresh gap and target binding.
   On that current basis the former action is no longer lawful; no other lawful
   published action is available, and the needed recovery capability is absent
   from the admitted catalogue. These facts are new inputs to selection, not
   another evaluation of the prior attempted edge. A4 permits precisely this
   branch after `post_retry` at 990-1007; A3 at 985-988 requires typed no-action
   for the unpublished desired action.
3. That no-action makes the current selectability/authority determination. Its
   `undeclared` cause would carry `out_of_frame` under the repaired map at 1035.
   Nevertheless 1024-1027 says it adds no core result because a prior closure
   exists. The prior `falsified` result retains the edge-fulfillment predicate;
   it cannot supply the missing current-selection result.

The two results need not differ in core value for the defect to occur; their
predicates and bases already differ. A carried prior decision may lawfully be
reused when its applicability supports the same consuming claim. The categorical
exemption is broader: it suppresses a newly performed material determination
merely because a prior closure is present.

The conflict is with both common and candidate owners:

- Common `requirements/README.md:162-174` requires every evaluation or decision
  outcome to travel through the core with its predicate and domain outcome.
- A `standards/ACTIVATION.md:945-954` requires one predicate-bound core value for
  each performed evaluation and distinguishes the step's other outcomes.
- A `standards/FOUNDATIONS.md:811-816,862-883` owns the predicate/domain recording
  and refinement mapping; 1080-1084 keeps predicates distinct through joins.
- A `standards/ACTIVATION.md:1712-1727` permits reuse only after checking exact
  applicability and material inputs. Prior existence alone supplies no reuse
  relation for the fresh gap.

**Required next action:** repair the ODD owner so any newly performed material
no-action/refusal determination carries its own predicate-bound result, or an
explicitly applicable result for that same determination, while keeping selected
action data separate. Align the function table, family row and source-disposition
