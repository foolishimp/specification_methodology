**The amendments that change the decision matter most.**

1. **Reuse: preserve history and assess current reliance separately.** P1's “a basis advance alone invalidates nothing” is too broad. Claude ACTIVATION already permits invalidation of affected reliance when material basis coordinates change. Use: “Advancement does not rewrite the historical result. Reliance on the new subject/basis requires the established applicability relation; affected reliance is withdrawn until that relation is established.” FOUNDATIONS explicitly interprets RF-005 as evaluation on the wrong basis, so scoped pointers are defensible as clarification. M3 independently repairs an actual blanket prohibition. Do not inflate the replacement count merely by combining these classifications. [Reuse owner](/Users/jim/src/apps/specification_methodology-claude/specification_methodology/v3/build_tenants/claude/standards/ACTIVATION.md:1705), [RF-005 interpretation](/Users/jim/src/apps/specification_methodology-claude/specification_methodology/v3/build_tenants/claude/standards/FOUNDATIONS.md:1045).
2. **Repricing: define the decision being evaluated.** An obligation state is a record; a material authorized choice establishing that state is a decision. TICKETS must define that decision's predicate and refinement under the common result law. It must not map lawful deferral to successful delivery or reuse ACTIVATION's “candidate is accepted” predicate. This is a focused repair to a domain exemption, with the core owner preserved. [Base exemption](/Users/jim/src/apps/specification_methodology-claude/specification_methodology/v3/build_tenants/claude/standards/TICKETS.md:1159), [common requirement](/Users/jim/src/apps/specification_methodology/specification_methodology/v3/specification/requirements/README.md:174).
3. **Effects: distinguish permission, intended outcome and actual mutation.** M1's evidence must exclude mutation within the relevant boundary; no authorized mutation is insufficient. M2 must represent unresolved completion, but a transport failure alone cannot override independently sufficient observations. Existing generic effect/recovery law supplies the shared dependency; the two profile repairs do not depend circularly on each other. A replay pass can faithfully reproduce an unknown-outcome message without proving external completion. [Traversal condition](/Users/jim/src/apps/specification_methodology-claude/specification_methodology/v3/build_tenants/claude/standards/TRAVERSAL_OCCURRENCE.md:1348), [UX contract](/Users/jim/src/apps/specification_methodology-claude/specification_methodology/v3/build_tenants/claude/standards/UX.md:347).
4. **Frames: select acquisition that serves the task.** Claude already permits direct deciding-owner sections when a derived view is unavailable or insufficient. A route need not create a frame. R1/R4 should compare a new frame, a smaller extension and direct anchored acquisition under the same task conditions. Their estimated bytes are design estimates, not measured actual-use qualification. [Acquisition owner](/Users/jim/src/apps/specification_methodology-claude/specification_methodology/v3/build_tenants/claude/standards/ACTIVATION.md:807).
5. **Checks: borrow the property, correct the implementation limits.** RC9 imports `context` and `build_interpretation` before authenticating helpers; the historical library loader authenticates before executing a module, but that does not cover the initial imports. The surface checker skips non-files before its symlink test. Its ownership-signal collector is called, but the current package receipt omits those signals. Adapt pre-execution authentication, complete path-kind handling and visible advisory output; do not claim the donor already proves all three. [Initial imports](/Users/jim/src/apps/specification_methodology-codex/specification_methodology/v3/build_tenants/codex/qualification/C3/rc9/package.py:25), [surface enumeration](/Users/jim/src/apps/specification_methodology-codex/specification_methodology/v3/build_tenants/codex/qualification/C3/synthesis/check_artifacts.py:294), [signal collection](/Users/jim/src/apps/specification_methodology-codex/specification_methodology/v3/build_tenants/codex/qualification/C3/synthesis/check_artifacts.py:494), [receipt fields](/Users/jim/src/apps/specification_methodology-codex/specification_methodology/v3/build_tenants/codex/qualification/C3/iteration-5/tools/check_package.py:34).
