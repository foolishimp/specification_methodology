# Native-first publication decision

The selected Product relation is standalone native STDO plus a separately
identified a_c/Graphify artifact representing the same frozen native payload.
No release-matched cohort or native dependency on Graphify was selected. The
Executive had unnecessarily coupled publication of the completed native RC to
slow supplemental model generation. Following the owner's timing feedback,
publication proceeds for the native test candidate while the supplemental
work remains selected and pending.

This changes delivery order and the initial published asset profile, not the
native Product member set, source meaning, immutable C/T/M, acceptance standing,
or the obligation to complete the requested representation. The native release
note already records that the supplement remains to be prepared. No completed
representation claim is made by this publication. The supplemental artifact
will receive its own exact identity, assessment and distribution record bound
to this native C; it cannot silently change the native RC or its claims.

The initial profile contains only the canonical native manifest and its SHA256
sidecar. Root constructs and checks their exact inventory in assets.json.
The preparation helper's assets command implements the earlier joint profile
and requires a .tar.gz; it is deliberately not claimed as executed for this
native-only profile. The unchanged publication-plan still independently checks
all listed asset bytes, installed payload, native object/annotation/parent,
source-candidate relation, carrier ancestry and exact guarded remote ref set.
The unchanged downloaded-assets checker checks the explicit two-file profile.

Builder RELEASE_METHOD Phases and Immutable RC Publication permit an honestly
scoped immutable test candidate before exact-cut acceptance. Human acceptance
and consumer adoption remain separate. The complete native subject and its
release-facing claims are fixed before publication; no future native change is
authorized under the same tag. The separate representation will not be described
as part of this native Product's immutable member set.
