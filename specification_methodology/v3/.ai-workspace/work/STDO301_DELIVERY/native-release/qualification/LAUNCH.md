# Fresh installed-route activation

Root prepared this launcher as a separately declared Writer under T-004. The
source candidate, native preparation and four task/oracle packets are unchanged.
This preparation has performed no model invocation. It must receive a nonauthor
readback before use.

For each of the four independently prepared task packets, Root creates one
prompt binding the actual sealed native commit, annotated tag, manifest digest,
installed directory and payload inventory. Append exactly that packet, not its
oracle, source-author material or any other task answer. Pin the complete prompt.
The actor starts from the installed README, acquires only relevant installed
owners, returns citations and an assessment, and never modifies the install.

`run_actor.py` starts one fresh Claude Opus 5.5 xhigh invocation. Safe mode disables
CLAUDE.md, skills, hooks and automatic context; restricted mode confines the only
tools (Read, Glob and Grep) to the installed working directory. MCP configuration
is empty and strict, shell and write tools are absent, session persistence and
resumption are disabled. OAuth remains available through the existing login.
The envelope is 15 minutes and USD 10 per task; no automatic retry is permitted.
The output directory is create-only. Private event streams remain under ignored
native run directories and are not release assets.

Root checks the actual initialization for the requested model and tool inventory,
rejects out-of-scope tool calls, verifies installed bytes afterward, and retains
the final answer plus truthful transport/usage/acquisition measurements. The
public measurement distinguishes supplied prompt bytes, acquired tool-output
bytes, reported token usage, elapsed time and uninstrumented peak active context.
It does not claim a context bound from cumulative token counts. On interruption,
timeout, unsupported CLI configuration or missing native identity, preserve the
attempt and stop dependent conclusions. Do not substitute an answer from another
task or source cut.

The launcher handles SIGINT, SIGTERM, SIGHUP and Python interruption, performs
bounded TERM/KILL process-group cleanup, and records interruption plus actual
group absence separately from the direct child's exit. It also checks for a
remaining group after ordinary completion. An uncatchable launcher SIGKILL or
host failure can prevent that record and cleanup; such a missing handoff remains
unresolved and requires external reconciliation before any retry.

A nonauthor assessor receives the exact task, independently fixed oracle and
final answer to judge each predicate. Passing these four tasks supplies bounded
amendment-use evidence, not whole-method acceptance or performance benefit.
