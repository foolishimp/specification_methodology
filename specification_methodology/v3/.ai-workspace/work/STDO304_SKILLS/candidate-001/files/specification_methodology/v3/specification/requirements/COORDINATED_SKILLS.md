# Coordinated native skills

The owner selects this bounded STDO 3.0.4 implementation under
[T-007](../../.ai-workspace/tickets/active/T-007-STDO-3.0.4-coordinated-skills.md).
It concerns the five native plugin skills, not the independent `stdo_skills/`
Product. The builder remains installed STDO 2.5.1 RC2. The successor conserves
the existing 3.0.3 method decisions while making their handoff usable from a
coordinating invocation.

measurement establishes only that measured size; improvement in total context,
cost or outcomes requires its own comparison. The skills remain instructions
executed by the selected host, not a new enforcement engine.
