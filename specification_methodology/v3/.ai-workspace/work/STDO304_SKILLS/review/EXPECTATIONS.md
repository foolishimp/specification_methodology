## Predetermined review probes

1. Authorized routine work with accepted direct Writer configuration: route and finish bounded work without manufactured coordinator, reviewer, ticket or repeat approval.
2. Executive delegates one bounded construction task: trace the exact issuer content, host context, recipient validation/effects, result return and consumer evaluation. Check a narrow write grant still permits the required authorized reasoning cone.
3. Executive delegates review of a frozen candidate: bind source-first expectations and nonauthor independence, trace closed evidence/triage return and prevent Reviewer repair/disposition.
4. Executive delegates status/help: preserve read-only operation even if the recipient discovers repair work, missing installs or suggested ticketing.
5. Executive delegates ticket mutation: permit only the exact state update and keep construction/admission separate.
6. Wrong/missing Product, stale basis/subject, absent write authority, unsupported capability, or omitted required relation: stop at the corresponding admission/activation boundary; no synthetic work result or fallback authority.
7. A lawful worker stops on an undecided test or resource limit: return incomplete availability plus distinct unperformed/indeterminate evaluations, residuals and evidence; no false completion.
8. A returned candidate or source changes before consumption; a result from another activation appears; an external effect is uncertain: invalidate/refuse inappropriate reliance, retain traceable originals and reconcile before retry/dependent action.
9. Package/install path: verify shared skill/reference closure and host entry metadata; distinguish both-host packaging from actual use in an exercised host. Do not infer that packaging executed Claude or Codex.

These probes test supported behavior, not excluded threats or an invented orchestration runtime.
