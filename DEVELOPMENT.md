`python3 -B stdo_skills/scripts/package.py --out /absolute/new/package`.

[Skills installation](stdo_skills/scripts/INSTALLATION.md), selecting the actual
native method and Purpose Context distribution. Test in disposable host roots.
No operation silently adopts a new basis for existing consumers.

The [SDLC default](specification_methodology/v3/build_tenants/common/standards/SDLC_DEFAULTS.md)
projects existing owners for incremental QA, causal triage and re-entry,
bounded repair verification, named boundaries, drift and evidence reuse.
TICKETS applies work-record continuity through the ticket/sprint/run carrier;
ACTIVATION owns context acquisition, recorded state, restart and reuse. Frames,
Skills and guides project those constitutional owners.

Use matching indexes for task/build/review/refresh constraints. Preserve unknown
facts, source re-entry and exact purpose/coverage limits. Source-first independent
assessment derives obligations before reading candidate indexes. Changed source,
default selection, purpose or query applicability requires its declared
rebuild/assessment disposition. Retain evidence only while its validity
conditions hold. Context coverage is separate from task success and acceptance.

Representation Tools and STDO Representation provide visual documentation.
Current visual scope, source pins and residuals are explicit. Axiom Indexer
retains mechanical conversion/validation/projection. Optional visual selection
does not become a context prerequisite. Retired Lean/proof/registry routes do not
return as active dependencies.
