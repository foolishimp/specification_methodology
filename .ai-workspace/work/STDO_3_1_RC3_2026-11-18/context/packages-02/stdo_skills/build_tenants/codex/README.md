# Codex Skills binding

The current binding is [current/DESIGN.md](current/DESIGN.md). Install with the
shared [development installer](../../scripts/INSTALLATION.md), selecting
`--host codex`. Core instructions remain native-method owned; context uses the
shared thin adapter and the independent Purpose Context Product. The current
visual skill is installed only when a visual component is explicitly selected.
Previous construction evidence retains its original scope and identities.

Continue with [Getting Started](../../GETTING_STARTED.md) for explicit first use,
purpose selection and expected work/review outcomes.
