# Visual requirements

The November 12 scope replaces the former mixed Product requirements. Their
exact prior text and retired files are retained in the alignment preimages and
archive; retirement does not satisfy an undelivered requirement.

| ID | Current required outcome |
|---|---|
| AC-R-V01 | Bind selected Product/source/model identities and preserve exact source grounding and unresolved meaning. |
| AC-R-V02 | Preserve declared records, directed relations, qualifications and reversible model/carrier identity. |
| AC-R-V03 | Offer portable visual reading, full record/source inspection and useful 2D/3D navigation. |
| AC-R-V04 | Distinguish structural checks from interpretation fidelity, acceptance, proof and code correctness. |
| AC-R-V05 | Invalidate affected reuse on source, authoring, model or machinery change and retain prior evidence. |
| AC-R-V06 | Operate the visual public package without retired context/workflow/formal modules. |

[Project use](project-use.md) and [code traces](code-realization.md) refine these
outcomes. Value/fidelity and independent release qualification remain separate.
The former AC-R-001–015 mixed scope, PU-05/07 agent delivery/composition, formal,
FD and algebra-context obligations are historical or withdrawn unsatisfied.
