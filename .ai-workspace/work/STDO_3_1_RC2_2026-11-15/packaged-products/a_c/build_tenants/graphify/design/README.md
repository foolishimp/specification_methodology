# Visual implementation design

`ac_project.py` binds a Product Definition and exact source through the selected
STDO manager, prepares authoring tasks, validates submitted source grounds and
builds a reversible carrier plus offline explorer. `ac_generate.py` owns the
shared generation contract; its record schemas preserve existing model formats.
`ac_graph.py` owns declared model validation, closure and carrier round trips.
`ac_explore.py` renders full records and source navigation without context panels.
`ac_code.py` adds selected structural observations and authored source/code links.

Generic local file guards reject redirects and escaped selections. Source,
model, task, answer and machinery identities invalidate reuse. Retired proof
metadata is refused, not ignored. Optional source-anchor repair preserves all
non-grounding meaning and retains original submissions.

No active formal, registry, task-context or support dependency remains. Archived
runtimes are required for historical runs selecting those contracts. The public
manifest identifies the current versioned portable visual runtime. The cohort
binds complete Product membership, publication and qualification separately.
