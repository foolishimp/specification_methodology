# STDO Representation intent

Make exact STDO source understandable as visual documentation, preserving
source authority, conditions, exceptions, relations, coverage and unresolved
interpretation. Improve reading and source navigation through explicit models.

This Product owns STDO-specific interpretation and visual artifacts. It does
not own a context registry, agent routing skill, workflow executor or formal
checker. Purpose Context owns the separate context-index method; STDO Skills
owns its host adapter. Old mixed-scope contracts and evidence remain historical.
