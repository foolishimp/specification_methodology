# Finite final assessment protocol

This is a plan derived from the retained source-first expectation set, not a verdict. It uses two bounded closures so semantic assessments may be referenced by the final carrier without inventing a circular subject.

1. **Semantic subject.** Freeze exact native A, current rule/index/purpose/query bytes, current native and Skills instructions, the visual declaration/model/source map, predecessor dispositions and retained actual-use evidence. Recompute the packet's exact member digests. Supply governing deciding clauses and the prior source-first expectations to an actual fresh Claude-family session. The model must distinguish original evidence, operator conservation observations and author claims. It returns per-claim semantic judgments, per-query supported/falsified/unknown judgments, material findings with finite falsifiers, evidence reuse applicability and explicit residuals. Do not convert unknown to supported.
2. **Final identity and packaging closure.** Once B, companion tags and assets exist, bind the reviewed bytes to those objects, check interactions/pins/package composition, and supply any material delta to an actual independent assessment. Unchanged semantics are reused by exact-subject mapping, without another universal semantic review. A final identity attestation alone does not erase a semantic defect.
3. **Publication closure.** Root owns remote expected-object checks, one atomic push, public acquisition and installation/readback. These remain unperformed until observed. The final assessment can be extended with the returned exact evidence; no prepublication report claims they passed. Acceptance by the owner and consumer adoption remain separate.

## Exact input package

- A commit/tag object/subtree/manifest plus verified installed file inventory.
- Release claims, six namespaces/dependency relation, per-claim predecessor dispositions and changed-path author-family map.
- Both final index directories: ordered sources and complete deciding source text, canonical index digest, purpose, query complete JSON plus canonical query/corpus digests, source-coverage/dispositions, rebuild receipt and unknown/gap output.
- Current Skill/default/ticket source; source-to-received-context preservation map for retained trials. Original request/inputs/output/effects and failed/repaired attempts remain separate.
- New visual exact source/model/provider pins, bounded coverage/residual declaration, source fidelity and reading evidence.
- Current package/install/removal/negative-control outcomes for both host layouts and the context-only path. Automated host pickup is outside the claim unless observed.
- Final B/tag/product trees, companion member inventory, asset hashes and refgraph.

The final packet is a measured, explicit selection of sufficient deciding inputs. If the complete family will not fit a usable context, partition by claim with a shared cross-Product interaction assessment. No silent clipping or source replacement by author summaries is allowed. Actual CLI init/result/stop/tool metadata and raw output are retained. A tool-disabled request is not asserted to be an enforced clean room.

## Runtime assessment recording

An external Purpose Context assessment has exactly index_sha256, corpus_sha256, query_sha256, status, evaluator and nonempty evidence. The operator may serialize the Claude result into this shape only when that result explicitly names and judges the same complete query/index/corpus. A machine-readable supported field is not authored to make coverage true. The runtime checks subject equality but does not authenticate assessor identity; this report and raw CLI provenance supply the external judgment chain.

## Scope control

Reuse unchanged qualifying evidence under explicit validity conditions. Do not demand whole-method self-qualification, C3 qualification, formal/Lean proofs, automatic host discovery or a review of every local repair. Material repairs receive the smallest sufficient recheck against the affected original claim.
