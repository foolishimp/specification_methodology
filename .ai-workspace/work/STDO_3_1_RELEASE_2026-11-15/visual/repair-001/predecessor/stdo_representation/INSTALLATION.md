# Install and use STDO Representation 3.1

Extract the cohort tooling ZIP into a new directory, preserving all independently
owned Product roots. Verify its exact inventories and public manifests. Open
`stdo_representation/build_tenants/a_c/representation/stdo-v3.1.0-rc.1/run/generation/proposal/explorer.html`
in a browser. The view embeds its source-linked model and viewer assets; ordinary
reading requires no Python, STDO manager, Lean or network request.

The artifact's README, SOURCE_BINDING.json and COVERAGE.md state its exact native
cut, selected members, source-section navigation, selected interpreted relations
and unrepresented meaning. Read them before treating any view as evidence.
`PUBLIC_MANIFEST.json` identifies the current portable artifacts and provider
pins; the cohort identifies complete Product/package membership.

For regeneration, select the exact native payload and manifest identified there,
the exact Representation Tools provider, this Product Definition and its installed
STDO 3.0.4 construction basis. Follow [Quickstart](QUICKSTART.md). Native source
identity, construction basis and distributing cohort remain separate. Historical
3.0.5 generated artifacts are available in their original release and are not
rebound or included as current 3.1 output.
