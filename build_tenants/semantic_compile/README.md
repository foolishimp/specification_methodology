qualification, provenance, grant, and acceptance prototype. Its schemas,
scripts, prompts, runs, and tests remain exact evidence for the bases they name.

The thin active Product does not invoke this directory. It uses accepted Axiom
Indexer `v0.1.0-rc.1` directly:

```text
LLM-authored a_c.STDO
  -> Axiom Indexer validation diagnostics
  -> LLM repair
  -> Axiom Indexer logical map
```

No provider receipt, compilation grant, structure-evaluation grant, semantic
selection ledger, or human acceptance is required for ordinary working-map use.
Those relations may support a separately claimed qualification occurrence, but
they are not Product members or dependencies.

Do not relabel a retained run as the active `a_c.STDO` program, copy its heavy
workflow into the native skill, or use its test success as thin-Product
qualification.
