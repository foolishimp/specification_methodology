accepted `a_c` model: `I/O/E/C/L/X/V/T/J`, `ResolutionSet_M`, and source routes

measurements. `F_D[v_carrier_admission]` evaluates or proves declared

admission judgment; it does not produce replacement carrier bytes or identity.

exact actor grant. Source STDO and the common requirements retain semantic and
Product authority.

The index is one passive graph-and-constraint Rule inside a frozen
GTL `ModulePublication`. It declares no GTL callable workflow, GraphFunction,
Job, Operator, Evaluator, embedded HoG execution, ABG runtime truth, event, or
continuation. In particular, it is not a frozen-GTL `GtlProgram`.
The external host owns the `F_P[v_reason]` traversal contract. Semantic
relations are not GTL GraphVectors merely because they are directed.
