# GTL Build Tenant

Identity: `urn:stdo-representation:build-tenant:gtl`

Status: exact carrier basis selected; `STDO.gtl 0.4.0` profile proposed; design
acceptance and program construction remain pending.

This tenant produces `stdo.gtl`: a compact authored GTL declaration program
containing Source STDO semantic atoms, typed edges, and passive constraints for
direct ODD `F_P` LLM traversal.

The tenant owns its GTL mapping, canonical bytes, projection mechanics, and
measurements. `F_D` evaluates or proves declared structural properties of those
results. `F_H` owns semantic selection and acceptance. Source STDO and the
common requirements retain semantic and Product authority.

The program declares no GTL callable workflow, GraphFunction, Job, Operator,
Evaluator, embedded HoG execution, ABG runtime truth, event, or continuation.
The external host owns the `F_P` traversal contract. Semantic relations are not
GTL GraphVectors merely because they are directed.

See the exact [GTL basis](design/GTL_BASIS.md) and proposed
[`stdo.gtl` profile](design/GTL_REPRESENTATION_PROFILE.md).
