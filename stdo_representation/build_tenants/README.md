# STDO Representation build tenants

The current `a_c` tenant owns STDO-specific source-semantic authoring under
[CURRENT_MODEL](a_c/design/CURRENT_MODEL.md). The current `axiom_indexer` tenant
derives the program, map and native projections from that same model through
exact provider mechanics. These are composed representations of one source,
not rival authored truths. Historical GTL, schema and semantic-compiler tenants
remain evidence outside the current member set.
