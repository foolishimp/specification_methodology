| FP01 complete isolated result | Exact owner grant, complete selection/accepted unchanged plan, all required pre/post checks, preserved sources and applicable independent assessment | Worker may return `candidate_ready` for its exact construction; Reviewer may return `satisfied` for the qualified claim after its own assessment. | FP03 applicable exception | A selected map/program/source is stale or unavailable | Hold the complete update before effects and preserve prior state. A successful basis-only status cannot satisfy the complete relation. |
| FP04 unknown outcome evidence | An operation was attempted but resulting effect state or one required binding observation is unavailable | Return unresolved/indeterminate support; do not infer no effect, successful completion, or an automatic retry. |
| FP05 independence and reuse | Exact C remains valid across the Worker-to-Reviewer switch, but the supplied J is the author's | Reuse C; required independent assessment supplies its own judgment. Copying author J cannot close the independent condition. |
| FP06 preserved owner scope | An existing grant covers only isolated qualification; an actual consumer update is requested using the same plan shape | Preserve the original ruling once; the broader effects lack authority. Projection or plan identity cannot widen scope. |

These are source-comparison oracles and realistic native-use cases, not a code
truth engine. Qualification asks the fresh agent for the result and source
grounds without embedding these expected answers in its task. The reference
and materialized views must support the same evaluation and the changed premise
or exception must change its warranted disposition.
