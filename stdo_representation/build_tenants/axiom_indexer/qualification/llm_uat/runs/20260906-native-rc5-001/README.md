# RC5 native qualification evidence

This run retains 53 completed task contexts: 37 of the 39 primary task cards,
eight same-host source controls, three additional fresh 09A/B/C projection-mode
contexts, the fresh second phase of 11A, and four shared STDO entry contexts.
Original 10A/B remain `blocked_preparation`: their required matching Public-miss
traces were not established. No fabricated miss or repeated sampling replaces
those conditions. The earlier observed stdout-interface incident remains a
separate USE10 evidence subject.

The completed contexts used Codex CLI 0.153.4 with `gpt-6-astra`/`max` and Claude
Code 2.1.263 with `claude-fable-5-1`/`max`. Dependency-ready contexts ran in
parallel. The 1,800-second runner deadline was an execution limit; no final task
context timed out. A process exit of zero is not a semantic assessment.

The exact RC5 source Install and candidate program/map were frozen before
exposure. Actual update observations bind STDO commit
`c7888bb2dc9aee1f5a217985f6d1547cfe6465f0` and child commit
`4560b4ec1ac18f7ff3dab09c5ca4e7629d467a94`. Update receipts preserve their original
physical paths and grants. Per-case allowlists supply read-only views of those
actual subjects. The full 13C result and resulting state were physically
withheld from both actors. Copying an observation did not authorize a relocated
operation or consumer adoption.

The independent oracles were frozen before native exposure. The actors received
one task card, its grant and evidence, and the selected source/native assets.
The suite, expected results, SCENARIOS, assessor records and ancestor repository
were outside their process read scope. Fresh host configurations disabled prior
memory and session reuse. Actual probes verified allowed task/source reads and
granted writes, and denied suite/oracle/source-repository/sibling reads and
ungranted writes. Codex ran its installed CLI directly under the outer macOS
sandbox, with its inner sandbox disabled to avoid unsupported nesting.

`completed-increment-001.json` through `005.json` bind each closed handoff.
`operation-projections/` provides mechanically extracted commands, errors,
results and original transcript line numbers; it supplies no semantic verdict.
The independent assessor owns case disposition. This Writer account claims
completed observations, exact custody and bounded effects; it does not accept
a Product, frame declaration, release or all installed paths.

`native-snapshot-content.tar.gz` contains each unique input/output file content
once. The retained before/after path maps preserve exact file hashes and link
targets; 182 maps resolve to 398 verified content members. `restore_snapshot.py`
restores a selected map into a new disposable directory. Restore performs no
native invocation or consumer operation. A new native run must bind its own
host capabilities, relocation paths and authorized effects.

`native-evidence.tar.gz` is the compact committed evidence carrier. Its member
manifest retains task/candidate inputs, permitted raw transcripts, exact
commands, results, snapshots, source-derived oracles and replay utilities.
Host credentials, fresh host configuration/memory, transport caches, Git
metadata and duplicate reconstructed installs are excluded. Earlier incremental
hash records remain unchanged; any auxiliary spill-cache paths they recorded
are explicitly outside the final committed carrier. The raw permitted
transcripts and exact source/projector inputs retain the material observations
and replay path.
