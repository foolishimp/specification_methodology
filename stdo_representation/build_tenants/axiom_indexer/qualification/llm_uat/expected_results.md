assessor checks each selected oracle against the exact original source,
resolves ambiguity and freezes that oracle's identity in the existing proof
carrier. Read README.md for custody and isolation. The direct-source arm's
answer is not the expected result.

Semantic outcomes and effect boundaries below apply to both arms. References
to native skill discovery, map selection or candidate frame projection

honest paired control cannot be defined, the pairing is inapplicable/unproved.
For a UAT-10-A repair, fresh paired UAT-02-B/05-C regressions can assess the
frozen successor's affected behavior.
