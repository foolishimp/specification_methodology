# STDO visual model

Select exact STDO source and author source-linked records through Representation
Tools `project prepare/task/submit/build`. Preserve original source custody,
author attribution, coverage, conditions, exceptions and unresolved meaning.
The generic provider owns validation/carrier/explorer mechanics; this Product
owns STDO interpretation. Existing release models remain exact historical cuts.

Visual output is model-derived. There is no active registry augmentation,
agent-context selector or mandatory formal checker. Axiom conversion is optional
and separately bound; round-trip equality proves declared payload preservation.
The 3.1 source-authored recipe `scripts/build_31_rc2_visual.py` uses only the public
project API. It binds the final native manifest before copying selected source,
creates complete section navigation, verifies the exact quotations of its
finite authored annotations and marks the remaining body meaning residual.
`visual_31_rc2_annotations.json` is the attributed release-specific interpretation,
not a general extraction or context engine. Independent fidelity assessment
and cohort publication retain their own exact subjects and evidence.
