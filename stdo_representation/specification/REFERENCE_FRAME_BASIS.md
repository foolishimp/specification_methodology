1. Constitutional trace: bind current Goals, Intent, Product, requirements and
   design to the exact affected public contract; scope changes re-enter owners.
2. Source fidelity: an LLM judges authored interpretation against exact frozen
   source, retains conditions/exceptions/dependencies and explicit uncertainty.
3. Symbolic integrity: validate identity, source routes and reference closure;
   derived views preserve exact model/program content and freshness.
4. Mechanical behavior: verify declared conversion, validation, projection and
   joining contracts using positive and refusal cases.
5. Actual native use: fresh host/agent evidence is required where release claims
   promise that behavior; a CLI help result or historical run is insufficient.
6. Release identity: complete exact Product member, source and provider closure
   is required before release; packaging is separate from semantic acceptance.

## Roles and limits

The Executive coordinates material Product/dependency boundaries and makes only
its granted dispositions. A separately bound Writer constructs inside its
territory. A Reviewer evaluates an exact frozen subject without repairing it.
The cohort Executive assigns required independent review; self-checks do not
stand in for it. Direct Writer entry remains available for a sufficient admitted
bounded task. The actual shared host has no enforced acquisition gate; no
stronger isolation or provider attestation is claimed.

## Reuse and invalidation

Reuse requires the same question, exact subject/basis, support and valid result.
Source, definition, provider, member, dependency or contract drift invalidates
the affected claim. Historical C3 and 2.x records retain their original basis,
scope and limits. No blanket deterministic-operation classification or new
semantic acceptance follows from this builder adoption.
