## Product statement

STDO Representation owns the source-linked semantic representation of exact
Source STDO, the derived Axiom Indexer program/map and frame views, and concise
native instructions for bounded source-reenterable use. An LLM authors meaning
from the frozen corpus. One declared a_c model is the canonical authored
representation; all current views derive from it and retain its identity.

## Product terms

- Source STDO: the exact semantic corpus frozen for the selected release, with
  complete member hashes; its documents remain semantic authority.
- Current model: the LLM-authored a_c source-semantic proposal for that corpus,
  with explicit conditions, exceptions, dependencies, latitude and residuals.
- Carrier: the a_c provider's checked encoding of that model under its exact
  public contract. Structural admission is not acceptance of methodology truth.
- Axiomatic Program: the Axiom Indexer view derived from that unchanged model
  under the declared reversible conversion contract.
- Logical Constraint Map: Axiom's deterministic index over that exact program.
- Frame Index: declared source-grounded membership for bounded retrieval. It
  neither creates an evaluation contract nor decides task applicability.
- Source Route: a logical URI with exact source-member binding; physical paths
  and line numbers are access/grounding evidence, never semantic identity.
- Residual: explicit unresolved meaning, omission or qualification with source
  re-entry and a consequence for the affected claim.

`a_c public build(checked answers) -> model + carrier + coverage`.
`Axiom convert(model, explicit source/frame bindings) -> program + preservation evidence`.
`Axiom validate(program, bindings) -> map | diagnostics`.
`Axiom project(program, map, explicit indexes) -> reference-only/materialized view | refusal`.

judgment over any changed section or imported normative premise. New or
changed semantics are freshly authored. Coverage is a processing account,
not semantic completeness. Source routes, actual grounds and unresolved
