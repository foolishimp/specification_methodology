# Explicit current frame-index use

Verify the exact 3.0.5 model/program/map, source freeze and Axiom Product
inventory from the release record. The program and map are under
`build_tenants/axiom_indexer/representation/stdo-v3.0.5/`. They derive from the
same current a_c model; the conversion receipt binds preservation. Never edit
a generated view to bypass a refusal or make a second authored model.

Inspect the map's `frame_indexes`. Each names its source-owned frame, scope,
clause/residual roots and source routes. Choose the applicable index explicitly;
no index supplies task applicability, actual premises, authority or acceptance.
Generated frame files are derived routes to exact owners, not additional law.

```sh
python3 <axiom-product-root>/build_tenants/core/code/ac.py project \
  --program <axiomatic-program.json> --map <logical-constraint-map.json> \
  --bindings <bindings.json> --frame-index <selected-index-uri> \
  --mode reference-only
```

Repeat `--frame-index` for explicitly selected overlapping frames. Use
`--mode materialized` for the same closure with unchanged program rows. Omit
`--output` for stdout; `--output -` names a literal file. A file output requires
the applicable grant and a path separate from inputs and sources.

Both modes retain exact identities, ordered local references and literal
qualifications, residual routes, source observations and program/map digests.
Supporting closure follows declared links; it does not infer missing semantic
premises. The original model and conversion payload provide exact record
recovery. Re-enter the source owner when a statement or selection is incomplete.

An absent premise, applicable exception or unknown fact retains its distinct
consequence under the source. An unperformed review has no assessment result.
A required review can hold dependent closure without automatically holding
otherwise authorized candidate landing. Severity and priority remain separate,
and old scale numbers cannot be silently translated. Cross-Product access
remains path- and purpose-specific; a shared leaf does not union grants.

Missing or stale sources, dangling roots and a mismatched map refuse the view.
Refreshing a source digest alone does not re-author meaning. Unknown attempted
effects require observation before retry under the existing grant. Return the
exact cause and owner re-entry; preserve unrelated valid results.
