# Direct and Graphify-assisted a_c pilot

Status: pre-answer protocol. `freeze.json` will bind these instructions, tools,
schema, task oracle, baseline manifests and run schedule before actors start.

Direct access uses the original LLM-authored a_c content and documentary
sources. Assisted access adds actual pinned Graphify discovery and complete
declared acquisition. Both have the same content, coverage disclosure, literal
search and source reader. Two fresh runs per condition and candidate, four
tasks per run, common output schema and resource envelope.

Source-only task expectations freeze before runs. Tasks include bounded
authored representations and applied judgments, with conditions, exceptions,
unknowns and source citations. Full native baselines are preserved; fresh task
outputs do not claim entire-method re-authoring or qualification.

Actors receive questions, access tools and output schema, without oracle,
peer answers, previous reviews or this conversation. Use the same actual model
and settings. Grading packets omit condition, usage and tool logs. Assess
source-owned meaning and permitted uncertainty rather than lexical similarity.

Record exact model/CLI/settings, prompts, tool definitions, source observations,
calls, emitted UTF-8 content, time and backend usage. Graph construction and
startup are separate costs. Graph neighborhoods do not establish required
context; source re-entry remains available in both conditions.

This bounded dogfood pilot locates effects worth repeated testing. It supplies
no RC, original-candidate acceptance or universal efficiency conclusion.

## Controlled access and scope

The original native baselines preserve every symbol, clause, residual and
frame index, plus an exact portable catalogue. Both conditions can inspect
the same native records, signatures, coverage and allowlisted source bytes.
Historical fidelity reviews, qualification returns and peer answers are
excluded from actor access. Graph discovery is an induced view of the actual
pinned upstream-loaded transport that removes those excluded source objects,
their occurrence/endpoint nodes and transport metadata. Governing acquisition
continues to use the exact complete authored model and checked selector
catalogue. A coordinate manifest does not count as reading its record payload.

The assisted treatment is the bundle of actual Graphify discovery and the
tenant's declared a_c acquisition support. Any measured difference belongs to
that bundle; this two-arm pilot cannot isolate their individual contributions.
Assistance is optional. Record uptake per run. A run that does not use the
additional tools informs the availability policy, not the effect of using them.

Two tasks author small structured semantic contracts; two apply source-owned
law to hypothetical cases with positive, negative and unresolved branches.
These are fresh meaning/application outputs, not the native a_c grammar or a
new full-method interpretation. Historical F_P authoring is common prior work
whose cost is unmeasured, never a zero-cost direct baseline. No graph extraction
or semantic authoring backend is called during graph construction.

## Runs and resource envelope

Use Codex CLI 0.162.1, the existing configured `gpt-6-astra` model and `max`
reasoning effort for every actor. Preserve actual invocation, backend events
and usage. Each invocation is a fresh ephemeral context, in an isolated empty
directory, with only the study MCP server. Disable shell, web, apps, unrelated
MCP servers and delegation. Documentary instructions are study data, never a
grant to change files or act outside the tasks. No oracle or study directory
is exposed through the source reader. Audit actual tool use.

Per actor: four questions; at most 24 attempted study tool calls and 160,000
UTF-8 bytes of emitted JSON text payload. Refusals count. Wire bytes, tool
definitions and startup are logged separately, not silently treated as free
backend input. Oversized required reads refuse; they never silently truncate.
Discovery displays may be explicitly token bounded and do not establish
context completeness. A 720-second process timeout bounds infrastructure
execution. Preserve failures and any retry under a new identity. Only a
confirmed infrastructure failure may be retried once, with unchanged tasks,
tools and prompt; poor answers and ordinary budget exhaustion are not rerun.
The server refuses acquisitions after 24 admitted calls; every further attempt
is still logged and refused. More than 24 attempts is an actor resource
violation, not a valid successful run. Any undeclared external tool/file access
also invalidates the run. Keep its answer and descriptive grades, count the
run as failed in the primary practical-result tally, and do not replace it.

## Pre-answer grading policy

The frozen source-only oracle owns finite semantic criteria and prohibited
claims, separately for each candidate. Its source-level judgments remain
distinct from the following benchmark summary. A nonauthor assessor receives
candidate, questions, oracle, original answers and exact sources, with neutral
run labels and no condition, tool log, usage or time. The oracle author and
assessor never author evaluated answers. Semantic equivalence earns credit;
preferred wording or use of graph tools earns none.

Per required criterion: met = 1, partial = 0.5, missed or incorrect = 0.
Critical criteria have weight 2, other criteria weight 1. Report each judgment
and an answer excerpt/reason. An asserted prohibited claim is reported
separately as a veto, never as credit for silence. The score denominator is
required criteria only. Partial means a preserved subset with no material
contradictory subclaim; a material contradiction is incorrect. A task passes
only if every critical criterion is met, no prohibited
claim is asserted, the weighted score is at least 80%, and at least one exact
documentary citation is valid and supports a deciding claim. Preserve permitted
uncertainty as the oracle specifies. A broad refusal does not earn omitted
positive or negative branches. Mechanical citation checks verify allowlisted
path, actual source text and supplied section/line coordinate; semantic
relevance needs assessment. Explain ambiguities rather than silently forgiving
or penalising them. Blinding can be imperfect if answers disclose tool use;
report any such disclosure without rewriting the answer.
Retain all criterion-level omissions: passing this threshold can coexist with
noncritical omissions and is not complete semantic coverage.

Primary comparisons are within each candidate: critical errors, task-pass
counts, semantic score and source support. Report all eight runs. Secondary
observations are tool/byte acquisition, backend tokens (input, cached, output),
elapsed time, graph calls/startup, graph setup and representation/storage size.
No dollar amount or total accepted-result saving is claimed without applicable
accounting. No correction cycle is performed in this initial pass: grade
findings identify repair burden, but a corrected-result cost is unmeasured.
