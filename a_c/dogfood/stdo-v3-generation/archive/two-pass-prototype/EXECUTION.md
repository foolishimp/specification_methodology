# Frozen execution choices

2026-10-18, before evaluated generation actors.

- Subjects and source inventories: exact Codex RC5 and Claude RC8 manifests in
  `corpora/`; no old a_c, reviews, maps or private assessment probes in actor input.
- Common authoring model: `gpt-6-astra`, reasoning effort `high`, existing CLI
  provider/default service settings. Freeze and compare the actual settings and
  CLI version, rather than assume global configuration remains unchanged.
- Source chunk envelope: 120,000 Unicode source characters, whole source lines
  and section-aware boundaries; small files pack together. Exact plans identify
  11 Codex and 19 Claude chunks. Prompt metadata/output are additional context.
- Graphify authoring view: at most 40,000 Unicode characters of explicitly
  bounded discovery data, with omissions and exact parent identity retained.
- Per-actor wall ceiling: 1,200 seconds. At most four concurrent model calls;
  use two workers in each of at most two simultaneous stage processes.
- Graphify extraction uses the exact pinned host prompt and actual upstream
  `fe085cedddde3a18554f8749b230bfe47f3dcce7`. Fresh F_P authoring follows actual
  source graph generation. Direct controls use identical source chunks and the
  same authoring contract with no graph data. No old authored model is supplied.
- A synthetic corpus smoke checks the actual CLI/source-graph/a_c whole path
  before the evaluated corpus runs; its usage is separate from study totals.
- Retain all infrastructure/actor/shape/source failures. A retry or supported
  repair has a separate immutable attempt and explicit reason; report all
  measured usage and time. No replacement hides the original failure.
- Missing chunks block normal assembly. A partial artifact remains explicitly
  partial, with refused/unresolved scope. Neither a source-processing ledger
  nor exact grounding proves interpretation completeness.
- The source-only private oracle is frozen before generated answers. It has
  six semantic probes per candidate; it is withheld from generation actors.
  Nonauthor semantic assessment and owner acceptance remain separate.

Run plans bind exact code, schemas, author prompts, source snapshots and chunk
identities before actor execution. Stage journals retain actual expanded actor
prompts, invocations, isolation, answers and reported usage. A single generation
repeat per treatment is a bounded construction/use observation, without a
population timing claim, dollar estimate or complete-method qualification.
