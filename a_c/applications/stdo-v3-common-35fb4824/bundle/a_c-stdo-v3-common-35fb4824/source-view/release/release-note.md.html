# STDO V3

This package contains the complete V3 method candidate. It is not a published
or accepted release.

Start with the [method entry](../standards/README.md). It locates the
foundations, shared methods, optional profiles, guides and task frames.
[Templates](../standards/templates/README.md) provide project starters;
[plugin guidance](../plugins/spec/references/GETTING_STARTED.md) explains
basis selection and the supplied workflow skills. The [licence](../LICENSE)
applies to the package.

Every method rule and task-frame source is contained in this package. A
consumer selects an exact accepted release and verifies its complete manifest
before relying on an installed copy. The package's presence establishes no
semantic qualification, adoption or publication.
