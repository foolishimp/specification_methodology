# ABIogenesis: files and logical constraints

Open [the unified reader](index.html) directly in a browser. The **3D / 2D /
Layered** buttons switch only the middle panel. Selected record, visible nodes
and connections, query, file context and reading trail remain in place.
It is one self-contained HTML file; reading requires
no server, network, LLM, Graphify installation or Lean installation.

All three renderers consume the same representation: the same 1,373 records,
495 external resolutions, exact links and 86 embedded source files. They differ
only in presentation. The layered view uses labelled cards arranged left to
right with directed connections. Scroll to navigate, use +/− to zoom, **Fit**
to see the displayed graph and **Focus**/**Expand one hop** to adjust scope.
Click a card to read it or an authored connection to inspect its qualifications.
Arrow keys move between cards; Enter opens the focused card or connection.
The Files sidebar and reading trail are shared across all modes. The old
`layered.html` remains a historical standalone export; `index.html` is the current
entry point. The prior pages are preserved with their exact identities in the
unification evidence.

The [unification delivery](../../.ai-workspace/work/T018_LAYERED_RENDERER/unified/DELIVERY.md)
records switching and shared-data verification. The
[T-018 predecessor](../../.ai-workspace/work/T018_LAYERED_RENDERER/DELIVERY.md)
retains the earlier layered view's test scope.

1. Open **Files** in the header. On a wide screen the file pane starts open.
2. Expand `specification`, then select `PRODUCT.md`. The adjacent list now shows
   records grounded in that file, across all record families. **Read file** opens
   the full source; **File map** shows those records and their existing links.
3. Search for **R10**, then select **R10 Replay and CLI agree on typed terminal
   outcome**. Follow **Authored: requires** to R9. The logical reading trail and
   the originating document are retained separately.
4. Use **Back to file** above the reading trail to return to that document's
   records and map. Use **Show in files** on a record to reveal its source path;
   it expands the folders and preserves your logical reading trail.
5. **All files** clears the document scope. Search and family filters remain
   explicit. The Files button closes/reopens the pane without resetting it.

The tree covers the **86 represented source files**, not ABIogenesis's entire
repository. Folder membership does not imply a logical dependency. Missing
embedded source is identified explicitly; grounded quotations can still be read.
