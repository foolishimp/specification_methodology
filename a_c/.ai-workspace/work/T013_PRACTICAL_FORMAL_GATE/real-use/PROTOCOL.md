## CLI selection and two-invocation limit

`transport/CLI_INSPECTION.json` pins the inspected native CLI and observations.
The user-visible shell wrappers are excluded: `codex-main` assigns CODEX_HOME
and injects danger-full-access. Those implicit settings were not tested and are
not selected. Invoke the installed regular native binary directly; inspect and
pin any unavoidable loader dependencies. Do not alter HOME/home/CODEX_HOME or
inspect credentials. The helper's existing protected pass-through remains.

Select the same explicit arguments for both arms: `exec --ephemeral
--ignore-user-config --json --sandbox workspace-write --skip-git-repo-check
--output-schema <exact-return-schema> -`. No model, reasoning-effort, profile,
permission bypass or model-configuration override. `--ignore-user-config`
selects CLI defaults rather than the user's wrapper/config defaults. Record
the actual reported model/settings if the stream exposes them; otherwise mark
them unknown. Parent-session model identity is not evidence of child identity.

The local executable's version/help establishes these flags for 0.164.0.
Official [non-interactive documentation](https://learn.chatgpt.com/docs/non-interactive-mode)
describes JSONL events, terminal usage and structured final output; the
[command reference](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
describes configuration isolation and workspace selection. These docs do not
prove account availability, final model identity or a successful local run.

At most two actual actor invocations total, one per arm. Proposed per-actor
wall limit: 900 seconds; outer supervisor: 1,000 seconds; output capture:

The Executive must select these actor bounds with the final plans. No automatic

times out or returns malformed output, retain it and assess the incomplete pair;
