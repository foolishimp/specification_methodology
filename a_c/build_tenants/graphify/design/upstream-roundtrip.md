# Installed pinned upstream roundtrip

Use `python AC_ROOT/scripts/ac.py upstream --model MODEL --carrier CARRIER --selections SELECTIONS --upstream CHECKOUT --runtime RUNTIME_JSON --output NEW_DIRECTORY` with the exact private Python invocation returned by the declared bootstrap. Selections is a nonempty ordered JSON array of `{"seeds": ["exact-record-id"], "budget_records": null}` entries.

The command uses the existing codec and upstream boundary: validate the exact model/carrier, derive selected views, invoke pinned Graphify build with dedup disabled, export, reload with the actual path loader, decode, and compare the reconstructed model and projections. It records `a_c.graphify.current-roundtrip/1`, exact model raw/canonical hashes, selected views, upstream commit/node/edge/decoded identities, bootstrap receipt, Python invocation/physical executable/prefix, loaded module paths/hashes and all retained output members. The output is an actual bounded execution observation, not source fidelity, Lean proof or acceptance. A fake/changed runtime, model-carrier disagreement, changed upstream or existing output is refused without selecting another environment.

Before invoking upstream or creating output, the output and every selected input must be disjoint in both containment directions. The shared `ac_fs_boundary.overlaps_existing` checks actual device/inode identities along both ancestor chains, including existing ancestors of a future output. Resolved path spellings alone do not identify case aliases on every filesystem, and the check makes no case-folding assumption. An inaccessible path fails without effects. Equal/nonfresh output and redirected output paths are refused. This includes an output nested inside the pinned checkout; detecting a dirty checkout after writing is not a valid containment boundary. Disjoint adjacent output remains supported. The helper's exact source is included in execution source pins and release inventories. These cooperative checks do not claim protection against hostile concurrent path replacement.
