# Axiom Indexer 3.1.0-rc.2

Mechanical model conversion, validation and source-linked visual projection.
The stable Product and directory remain; ordinary agent context discovery is
owned by Purpose Context, exposed through STDO Skills.

```sh
python3 -B build_tenants/core/code/ac.py --help
python3 -B build_tenants/core/code/ac_model.py --help
```

`ac.py validate/project` checks and renders explicitly supplied programs and
source maps. `ac_model.py convert/restore` preserves a supplied model through a
reversible program encoding. Callers select roots/configuration; the tool does
not invent applicability or semantic authority. Old `join`, `project-registry`
and the `axiomatize-corpus` skill are archived outside active source.
