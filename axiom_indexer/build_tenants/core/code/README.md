# Mechanical visual implementation

`ac.py` owns declared program/source-map validation and explicit visual
projection. `ac_model.py` converts and restores supplied models, preserving
records and metadata with exact receipts. No registry-context provider, agent
join route or authoring skill is part of this implementation.

Tests exercise explicit input preservation, source resolution, refusals and
projection. They do not qualify semantic interpretation or a new release.
