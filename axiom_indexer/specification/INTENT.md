# Axiom Indexer intent

Preserve an explicitly authored model in mechanically checkable, source-linked
forms for visual documentation. Keep identity, complete declared payloads,
references and source mappings inspectable and reversible.

This Product no longer owns authoring skills, text joining for agent prompts,
registry-context projection or ordinary agent discovery. Purpose Context owns
purpose-selected indexes. Semantic authoring and applicability stay with the
source owner; a valid or reversible program does not prove source meaning.
