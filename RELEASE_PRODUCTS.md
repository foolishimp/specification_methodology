# STDO 3.0.5 candidate Products and components

This is the required membership of the owner-selected **complete stable
3.0.5 candidate**. `stack_release.json` is its machine-readable binding.
An absent output or evidence record leaves the candidate incomplete.
This table is a construction obligation, not an assertion of publication.

| Product | Required 3.0.5 components | Exact binding required |
|---|---|---|
| Specification Methodology v3 | Current method corpus, native `spec` plugin, manager, installed documentation and proof reader | Semantic freeze S, complete native cut A, installed manifest, current manager wheel and installed qualification |
| STDO Representation | Current model/program, logical map/index, unified 3D/2D/layered explorer and source/files navigation | Exact S member closure, source links, model identity, generated-view identity and independent semantic assessment |
| a_c Implementations | Graphify and executable Lean implementations, portable setup, exact-candidate verification | Exact Product subject, third-party pins, source-profile binding, real installed run and Lean evidence |
| Axiom Indexer | Executable validation/projection mechanics, schemas and output contracts | Exact Product subject, current program validation and dependency digests |
| STDO Skills | Codex and Claude host skill distributions | Exact current native workflow dependency, both host packages, representation/tool routes and qualification |

All five Products and owned release components use **3.0.5**. Third-party
dependencies keep their independent exact versions and provenance. Matching
labels alone establish no currentness or usability. Source archives, old
graphs, historical proof reports and older skill snapshots cannot satisfy a
current-candidate obligation.

The native five workflow skills remain the common workflow owner. Independent
host packages provide bindings and specialized representation/formal/code
routes without introducing another owner for `stdo-work` or method law.

The repository root coordinates this relation; it is not a Product. Product
ownership, semantic acceptance, installed qualification, publication and
consumer adoption remain distinct. [The release procedure](STACK_RELEASE.md)
defines complete closure and the immutable historical boundary. Published
3.0.4 remains unchanged and is the selected builder for this work.
