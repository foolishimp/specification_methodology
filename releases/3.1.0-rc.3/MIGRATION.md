# Migrating to STDO 3.1.0-rc.3

Select and verify the exact native RC3 manifest and matching six-Product assets.
An existing Product changes basis only through its own authorized adoption.
Existing installations and receipts are preserved; use a fresh explicitly
selected environment and the release's Getting Started instructions.

Re-enter any Product-specific contract that relied on ODD's mandatory runtime
ledger, evaluator sequence or replay API. Those implementation obligations are
intentionally removed from the generic method. Keep tracking, required evidence,
needed step-produced facts and reconciliation with authoritative workspace truth.
A generic register or an equivalent mechanism may serve that function. A Product
may still explicitly require its own ledger/replay design.

Product states the intended end state; move current epic planning to Goals.
Acquire release-matched context indexes and new exact-query assessment where
coverage is required. Old assessments and visual artifacts remain valid only for
their declared unchanged subjects; version labels transfer no coverage.
