A governed product records which release of STDO Builder builds it: the release's version and the sha256 of the release's manifest. It is recorded in the place the method already gives for what a product is built with; no new place, file or term is defined for it, and if the method gives no place that fits, say so and stop. Set-up writes the record from the release that is running. Only a command the user gives changes it afterwards. A run by any release other than the one recorded is refused before any step, and says which release is recorded and which is running.
